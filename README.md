# 📊 PR. 1 Fundamental Booster – Excel Project

## 🚀 Project Overview
This project demonstrates the practical application of Microsoft Excel formulas, functions, and data analysis techniques using three business-oriented datasets:

- 🎓 Student Performance Analysis
- 💰 Sales Data Analysis
- 👨‍💼 Employee Data Analysis

The workbook focuses on strengthening Excel fundamentals through real-world scenarios and formula-based problem solving.

---

## 📂 Workbook Structure

### 🎓 Students Grade Sheet
Key tasks completed:

- ✅ Total Score using `SUM()`
- ✅ Average Marks using `AVERAGE()`
- ✅ Grade Classification using `IFS()`
- ✅ First Name Extraction using `LEFT()` and `FIND()`
- ✅ Conditional Logic using `IF()` and `AND()`
- ✅ Rounded Values using `ROUND()`
- ✅ Text Transformation using `UPPER()` and `LOWER()`

### 💰 Sales Data Sheet
Key tasks completed:

- ✅ Sales Analysis
- ✅ Discount Classification using Nested `IF()`
- ✅ Product & Region Based Reporting
- ✅ Date-Based Sales Tracking
- ✅ Conditional Business Rules

### 👨‍💼 Employee Data Sheet
Key tasks completed:

- ✅ Joining Year using `YEAR()`
- ✅ Years of Service using `DATEDIF()`
- ✅ Date Difference Calculations
- ✅ Salary Rounding using `CEILING()`
- ✅ Salary Floor Values using `FLOOR()`
- ✅ Employee Data Analysis
